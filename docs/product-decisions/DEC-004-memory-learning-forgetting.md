## 確定事項

1. **有用な情報を選択的に学ぶ（選択B）:** Nagiは許可された日常利用から選択的に学習する。重要な意思決定・個人情報などの確認条件は下記の2026-11-25追加合意に従う。会話を無差別に永久保存しない。
2. **自然忘却（選択B）:** 有用性が低く長期間使われないMemoryを Active → Decay → Archive → Delete のライフサイクルで整理する。
3. **保護:** ユーザーが明示的に固定したMemory、継続中の重要なプロジェクト、重要な意思決定、定着した習慣などは単純な経過時間で自動削除しない。判断に迷う場合はArchiveに留める。
4. **自然な再学習:** DecayまたはArchive状態のMemoryは、ユーザーに役立てば再活性化できる。自然忘却で削除した情報は新たな観測から学習してよい。
5. **明示的な忘却は優先:** 「忘れて」と指示されたMemoryを利用対象から直ちに外し、既存履歴・Waybackなどから自動再学習しない。ユーザーが明示的に再開を許した場合は別。
6. **削除範囲の正確さ:** 完全削除を要求した場合はMemory本体、派生要約、索引、Context cacheへ反映する。元ファイル、Activity、Wayback、バックアップ、過去のCloud送信は管理境界が別なので、削除済みと誤表示しない。
7. **習慣の文脈:** 一度の操作だけを習慣としない。繰返しと利用者の採用を根拠に、どのTask・Workspace・用途で好まれたかを学習する。Nagi自身の独断の繰返しだけでユーザーの好みと断定しない。
8. **ユーザー指定を優先:** 「毎回こうして」「もう使わない」という明示指示は、暗黙学習より優先する。習慣は権限を増やさない。
9. **モデル非依存:** Granite、ELYZA、Qwen等を入れ替えてもMemory、Preferences、Habits、Profileを維持する。

## 学習経過の確認と訂正（2026-11-16／CONFIRMED）

[DEC-059 — 学習履歴とNagi Insights](DEC-059-learning-history-insights.md)では、学習の内容・経緯・実用的な影響を利用者が分かりやすく確認できる体験を定める。習慣として推定中の情報と、明示的な指示・確認済みの好みは区別し、ユーザーが誤解を訂正できるようにする。履歴を見せるために自然忘却・元Source削除・明示的な忘却を無効化しない。Activity／Wayback等の別履歴を永続Memoryの代用とせず、モデル非依存のMemoryと既存Permissionの原則を維持する。具体的なタイムラインUI・保存粒度・効果スコアは未決定。

### 成長経路の優先順位（2026-11-16追記／CONFIRMED）

[DEC-058](DEC-058-habit-first-learning-and-optional-teach-mode.md)により、Nagiの個人適応は**許可された普段の利用から自然に好み・習慣・反復作業を学ぶことを主経路**とする。ユーザーが事前に「教える」操作をしなくても既存の自動Memory／Learningの価値を目指す。**Teach Mode（仮称）は任意の補助機能**とし、学習済みHabitや反復作業の正式Workflow化には既存の明示承認を維持する。無制限な収集・監視や権限拡張を新たに許可するものではない。

## PX-08 — Memoryの自動学習範囲：バランス型B案（2026-11-17／CONFIRMED）

**採用範囲:** ユーザーはPX-08で**B案（バランス型）**を基本方針に採用した。Nagiは許可された情報を自然に学び、推測は推測のまま扱い、重要な内容はユーザーに確認する。この合意は既存CONFIRMEDの詳細化であり、全面的な事前確認や、無制限な収集・長期保存の採用ではない。

1. **許可された情報から自然に学ぶ。** 個々の有用な情報について毎回「覚えて」と指示させず、既存の権限・情報分類・所有範囲と収集除外条件の内側で、選択的なMemory／Preference／Habit学習を進める。
2. **観測事実・明示された内容と推測を区別する。** 推測に基づく学習候補は、保存・参照する場合も推測として扱う。未確認の好み・習慣・解釈を確定した事実や明示されたユーザーの意思と混同しない。ユーザーによる明示指示と訂正は推測より優先する。
3. **重要な内容は確認する。** 重要な学習内容については利用者の確認を求める方針とする。何を「重要」とするか、候補登録前／確定扱いにする前／支援へ反映する前などのどの段階で確認するか、確認手段や未回答時の挙動は2026-11-17時点では未決定とした。後続の確定事項は下記2026-11-25追加合意に従う。
4. **既存の保護・安全境界は変更しない。** [DEC-003](DEC-003-memory-classification.md)の機密分類とUser／Profile等の分離、[DEC-005](DEC-005-files-albert-memory-lifecycle.md)のSource・閲覧除外と削除連動、本文の自然忘却・明示的忘却、[DEC-058](DEC-058-habit-first-learning-and-optional-teach-mode.md)のHabit-first／任意Teach、[DEC-059](DEC-059-learning-history-insights.md)の根拠・訂正の可視化、[DEC-002](DEC-002-cloud-ai-data-sharing.md)の別許可による外部送信を維持する。Memoryの発見・確認だけではWorkflow保存・実行やActionのPermissionは発生しない。

### 2026-11-25 — 4/12 Memory学習の詳細 B案（CONFIRMED）

- **自然学習:** 許可されたユーザー自身の入力・操作から、明示された好み、日常の習慣、作業方法、継続中の作業を選択的に学ぶ。個々の項目について毎回の保存指示を求める必要はない。習慣の学習は反復と文脈を考慮する。
- **本人確認:** 重要な意思決定には本人の明確な意思を確認する。本人が既に明示した決定については重複確認を求めない。重要な個人情報は長期記憶化する前に本人に確認する。
- **学習状態と利用範囲:** 観測（本人の発言・操作等）、推定（Nagiの解釈）、確認待ち（本人の判断が必要な候補）、確認済み（本人の意思を確認した内容）を区別する。許可された推定の利用は、低リスクな提案や候補の順位付け等に限る。推定を確定事実、本人の指示、権限の根拠として扱わない。確信度と保存・参照・操作の権限は独立して扱う。
- **未回答と候補の整理:** 確認が必須の情報は、未回答や無視を承認とみなさず、確定情報として保存・利用しない。日常作業を妨げないよう控えめに提示し、[Nagi Insights](DEC-059-learning-history-insights.md)から後で確認・訂正・却下できるようにする。古くなった未確認候補は自然に整理する。
- **由来と認証情報:** 外部由来の内容は[DEC-113](DEC-113-untrusted-content-and-prompt-injection.md)に従って候補に留め、本人確認前にCanonical Memoryへ保存しない。パスワードやAPIキー等の認証情報は、Secretを含めてMemory学習の対象外とし、[Nagi Secrets Service](DEC-086-nagi-secrets-service-hybrid-key-protection.md)の別の管理境界に従う。
- **既存の学習・保護境界:** 確信度、重要度、反復、継続期間、周期性、本人の保護指定を区別して評価する既存の重み付けと、自然忘却・明示的忘却・モデル非依存を維持する。[DEC-117](DEC-117-user-data-encryption-and-lost-device.md)に従い、MemoryとProfileは常時暗号化する。Persona／Secretの適用境界は[DEC-057](DEC-057-growing-personal-agent-os.md)に従う。

## PX-09 — Memoryの保持・忘却・管理体験（2026-11-17／基本方針CONFIRMED）

**採用した基本方針：B案「自然忘却＋ユーザー管理」。** Nagiは既存の収集許可・情報分類・所有範囲・Source・Permissionの内側でMemoryを自然に整理し、重要なMemoryは保護する。ユーザーは必要なときに保持内容を確認・訂正・保護・忘却できる。利用者が毎回手動で整理することを前提にしない。これは本DECのActive → Decay → Archive → Delete、重要Memoryの保護、明示的忘却優先を置き換えず、管理体験として整合させる。自然忘却による削除と明示的忘却は区別し、明示的忘却後は対象Memoryを直ちに通常利用から外し、過去Sourceから黙って再学習しない。Archive、派生Memory、Source、Backup、Waybackの管理境界と、削除状況を正確に示す既存方針も維持する。

**将来の製品方向：C案の高度な重複統合・矛盾検出を追加する方針をCONFIRMED。** B案を基本としながら、将来この高度なAI支援を追加する方向とする。これは現在の機能実装、統合結果の自動適用、特定の提供時期を意味しない。ユーザーの明示的な訂正・保護指定、Sourceの由来、Memoryの所有Scope・分類・現行Permissionは引き続き尊重する。重複・矛盾を検出した後にどう提示し、統合・更新するかは未決定である。

## 2026-11-25 — PX-09 重み付けとPersonaに応じた自然忘却

**CONFIRMED（ユーザー合意）**

- 長期にわたり定着した習慣は一時的な行動・短期の傾向より忘れにくくする。利用回数だけではなく、重要度、継続性、周期性、実際の有用性、本人の明示指示・採用等を区別して評価する。
- Nagi Personaの利用文脈に応じて自然忘却を評価する。年次作業等の低頻度だが有用な記憶を、利用頻度の低さだけで削除しない。Secret等の利用が制限された記憶について、通常Personaで使われないこと自体を減衰の根拠としない。Persona間の異なるPreferenceを直ちに矛盾とみなさない。
- 記憶の保持・忘却と、現在の状況での自発的な参照／提案の可否を分離する。既存の明示忘却、再学習抑止、保護指定、所有Scope・現行Permission・Sourceの削除連動を維持する。Persona／Secretの製品方針はDEC-057（関連更新PR #249、統合時に整合を確認）に従う。
- 長期間の利用による記憶蓄積でストレージを圧迫したり読み出しや日常動作が著しく劣化したりする設計を避ける。容量・検索応答性の長期スケーリングを重要な設計・評価条件とし、DEC-013のHardware-Adaptive Memory Engine・性能検証と整合させる。容量逼迫を理由に保護された記憶や本人の明示忘却状態を無断で失わない。

**PROVISIONAL:** 重み係数・具体的な減衰曲線・日数・閾値（既存7/90/180/365日等は暫定のまま）、Persona／Secretの具体的な保持・保護方式、ユーザー操作UI、矛盾検出／統合の適用条件、保存量上限・整理方法・性能数値・適用版。既存の自然忘却と明示的忘却を区別し、Release／Activation／Implementation Spec Gateを変更しない。
