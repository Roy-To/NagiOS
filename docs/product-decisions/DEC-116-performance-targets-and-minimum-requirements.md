# DEC-116 — 性能の仮目標値・基準端末・最低動作環境

**状態:** CONFIRMED（基準端末の進め方、仮目標値を先に置いて実測で見直す方式、下記の仮目標値と最低動作環境の案を作業目標として採用）／PROVISIONAL（各数値は実測後に見直す仮の値、測定方法、実機の調達、適用版）  
**最終合意日:** 2026-11-20  
**適用候補:** Linuxカーネル＋Nagi userlandのLinux image。0.1の独自カーネル版の受け入れ条件は変更しない  
**関連:** [DEC-020](DEC-020-ai-os-interaction-path.md)（8GB級での実用目標と先行性能試験）、[DEC-052](DEC-052-physical-test-device-candidates.md)、[DEC-067](DEC-067-nagi-power-deterministic-resource-management.md)、[DEC-094](DEC-094-resource-manager-linux-baseline-custom-scheduling-research.md)、[DEC-102](DEC-102-hardware-support-staged-multidevice-linux-drivers.md)、[DEC-103](DEC-103-testing-release-evidence-baseline-ai-assisted-staged.md)

## 目的と背景

DEC-020で、8GB RAM級の端末で純正アプリの日常操作とローカルAI連携を両立させること、起動の成否ではなく前景の応答性とAI Taskの品質を実測すること、0.3完成前から性能試験を始めることがCONFIRMEDとなっている。一方、具体的な数値と基準端末は未確定だった。目標がないと、実装担当が「速くなった／遅くなった」を判断できないため、本DECで仮の目標値と基準端末を定める。

## 確定した仕様（CONFIRMED）

### Q1 — 基準端末

1. **当面は、QEMU（RAM 8GB・仮想CPU 4基）で数値を取り始める。**
2. **最初の実機の基準は、x86-64のノートPC（ThinkPad X13 Yoga Gen1クラス：第10世代Core i5、RAM 8GB）とする。** 将来のタブレット展開とも相性がよい2in1を想定する。
3. QEMUの結果と実機の結果は区別して記録する（DEC-020・DEC-103）。QEMUの結果を実機での達成とみなさない。

### Q2 — 数値の決め方

1. **仮の目標値を先に決め、実測後に見直す。**
2. 見直しの際は、変更前後の値と理由を本DECの決定履歴に記録する。

### Q3 — 仮の目標値（8GBのx86ノートを想定）

| 項目 | 仮の目標 |
|---|---|
| 電源オン → ログイン画面 | 20秒以内 |
| ログイン → デスクトップを操作できる | 5秒以内 |
| アイドル時のメモリ使用量（AIモデルは未読み込み） | 1.5GB以内 |
| キー入力から画面表示まで | 50ミリ秒以内 |
| スクロール・アニメーション | 60fpsを目標、最低30fps |
| 純正アプリの起動 | 1秒以内 |
| ローカルAI（3B級モデル・4bit量子化） | メモリ3GB以内、最初の文字が出るまで3秒以内（モデル読み込み済みの場合）、毎秒8トークン以上 |
| AI動作中の前景操作 | 入力の遅れが100ミリ秒を超えない |

### Q4 — 公表する最低動作環境（案）

> x86-64のUEFI PC、メモリ8GB、ストレージ64GB以上（推奨はメモリ16GB）

ARM・タブレット等は、対応した時点で追加する。

## 例外・禁止・安全境界

- 仮目標値は作業目標であり、達成済みの性能や利用者への性能保証ではない。未測定の項目を達成済みと表示しない。
- 仮目標値を満たすために、Permission／Policy、DEC-113の外部コンテンツの扱い、データの耐久性（DEC-090）などの安全・正確さの要件を緩めない。
- 0.1（独自カーネル版）のM30やRelease／Activation Gate、既存Acceptanceを変更しない。

## 未確定・暫定案（PROVISIONAL）

- 各項目の測定方法（計測ツール、計測の開始・終了点、試行回数、代表値の取り方）。
- AIの品質の測り方（日本語・英語の理解、Action選択の正しさ、Task成功率）と、その合格値。DEC-020の未確定事項と合わせて決める。
- 同時に開いておくアプリ・Taskのシナリオ、電力・温度の目標値。
- ストレージ64GBの内訳（OS本体、A/B更新用の領域、AIモデル、ユーザーデータ）。
- 実機（X13 Yoga Gen1クラス）の調達時期。DEC-052の実機候補への追加。
- 適用版と実装担当。
