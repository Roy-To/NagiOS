# DEC-114 — Web利用・開発者向けLinux環境・アプリ互換の説明

**状態:** CONFIRMED（Q1 Webはブラウザーで利用、Q2 開発者モードの隔離Linux環境と最低限ツールの同梱、Q3 利用者向け説明の趣旨）／PROVISIONAL（開発者環境の技術・範囲・同梱ツール、説明文の最終文言、適用版）／REVIEW NOTE（GUIアプリの扱い、関連DECとの整合）  
**最終合意日:** 2026-11-20  
**適用候補:** 一般利用者向けのアプリ環境、開発者・`builder`の開発環境。適用版は未確定  
**関連:** [DEC-017](DEC-017-third-party-developer-ecosystem.md)、[DEC-043](DEC-043-nagi-userland-independent-os.md)、[DEC-045](DEC-045-nagi-porting-toolkit.md)、[DEC-015](DEC-015-builder-role-review.md)、[DEC-071](DEC-071-nagi-native-app-creation-experience.md)、[DEC-084](DEC-084-nagi-permission-linux-sandbox-enforcement.md)、[DEC-113](DEC-113-untrusted-content-and-prompt-injection.md)

## 目的と背景

DEC-017により、一般向けのアプリ実行・配布環境はNagi Native Apps専用であり、Linux／Windows／Android等の既存アプリを無変更で動かす汎用互換レイヤーは標準搭載しない。例外的な互換性は別途の明示決定を要する。

本DECは、その方針のもとで残っていた3点を決める。(1) Webサービスの扱い、(2) Nagi上での開発に必要なLinux用ツールの扱い、(3) 利用者に互換性をどう説明するか。DEC-017の既存方針は変更しない。

## 確定した仕様（CONFIRMED）

### Q1 — Webサイトはブラウザー（Albert）で利用する

1. Gmail・文書作成・チャット・動画などのWebサービスは、Albertでサイトを開いて利用する。
2. Webアプリを、ホームへのインストール、専用ウィンドウ、アプリ単位の権限・通知を持つ「アプリ」として特別に扱う仕組み（PWA的な扱い）は、**現時点では採用しない。** サイトごとの権限は、既存のAlbertの仕組みで管理する。
3. 将来必要になった場合は、別途決定のうえで追加できる。本DECはそれを禁止しない。

### Q2 — 開発者向けLinux環境と、`builder`用ツールの同梱

1. **開発者モードを基本とする（A）:** ユーザーが明示的に有効にした場合に限り、**隔離されたLinux環境**の中で、cargo・git・コンパイラなどのLinux用CLIツールを使えるようにする。標準では無効とする。
2. この環境は開発用であり、一般向けのアプリ実行・配布環境（Nagi Native Apps専用）とは別扱いとする。DEC-017の「汎用互換レイヤーは標準搭載しない」に対する、開発用途に限った明示的な例外として位置づける。
3. **`builder`が使う最低限のツールは同梱する（B）:** Nagi上でのアプリ制作（DEC-015／DEC-071）に必要な最低限の開発ツールは、Nagi側で用意・管理し、開発者モードを有効にしなくても`builder`が使えるようにする。
4. 開発者環境と同梱ツールも、NagiのPermission／Capability／Policy、非特権AI、DEC-113の外部コンテンツの扱いに従う。環境があることだけで、ユーザーデータ・Memory・他アプリのデータへのアクセス権は得られない。

### Q3 — 利用者向けの説明

利用者に「今使っているアプリはNagiで動くのか」を説明するときは、次の趣旨で統一する。

> NagiではNagiアプリが使え、Webサイトはブラウザー（Albert）で利用できます。WindowsやLinuxのアプリはそのままでは動きませんが、移植しやすくするためのツール（Nagi Porting Toolkit）を用意していく予定です。

- 移植ツールの名称は、DEC-045の「Nagi Porting Toolkit」とする。`builder`（新規アプリ制作のRole）と混同しない。
- 移植ツールや開発者環境が完成するまでは、「用意しています」など完成済みと読める表現を使わない。

## 例外・禁止・安全境界

- 開発者モードの隔離Linux環境は、一般向けアプリの配布経路にしない。そこで動くツールをNagi Native Appsとして扱わない。
- 開発者環境から、Nagiのユーザーデータ・Memory・Secrets・他アプリのデータへ、明示的な許可なしにアクセスできないようにする。ファイルの受け渡しは、ユーザーが指定した範囲に限る方向とする。
- `builder`同梱ツールの実行も、既存の承認済み開発Task／Action Scope（DEC-015／016／018）に従う。ツールが使えることは、任意のshell実行の許可ではない。
- DEC-017の既存CONFIRMED（Nagi Native Apps専用、移植支援の優先順位、Level 0〜3、Public API、Package・導入・公開の別承認）を変更しない。

## REVIEW NOTE（assistantの整理・未承認）

- **GUIアプリの扱い:** 開発者環境でLinuxのGUIアプリ（エディターやIDEなど）を表示できるようにするかは未決定。表示できるようにすると、実質的に一般向けの互換レイヤーとして使われる可能性があるため、DEC-017の方針と合わせて別途判断する案。
- **関連DECへの注記:** DEC-017（例外の明示決定に該当する旨）、DEC-071（Nagi上での制作に必要なツールの提供）、DEC-045（利用者向け説明での名称）に、本DECへの日付付き参照注記を追加する必要がある。
- **Webの互換性:** Q1でWebサービスをAlbertで利用する方針としたため、主要なWebサービスがServoで動作するかが、Nagiを日常的に使えるかどうかに直接影響する。別論点として検討する。

## 未確定・暫定案（PROVISIONAL）

- 隔離Linux環境の技術方式（コンテナ・VMなど）、使うLinuxのユーザーランド、パッケージの取得方法、更新・削除の方法。DEC-043の「既存ディストリビューションをOS基盤として流用しない」との関係も整理する。
- 開発者環境とNagiの間のファイル受け渡し、ネットワーク、資源制限（CPU・メモリ・ストレージ）。
- `builder`に同梱する最低限のツールの一覧と、その更新方法・ライセンス。
- 開発者モードを有効にする画面と、有効時の注意表示。
- 利用者向け説明の最終文言（英語版を含む）と掲載場所。
- 適用版と実装担当。
