# DEC-057 — 学習・適応・継続によって成長するPersonal Agent OS

**状態:** CONFIRMED（Nagi OS全体の製品コンセプト、利用を通じた個人適応、モデル非依存の継続性、ユーザー主導の訂正・忘却と安全境界）／PROVISIONAL（学習品質の評価、具体的な個性・対話適応の方式、実装詳細・提供時期）  
**決定日:** 2026-11-16  
**対象:** Nagi OSの中長期的な製品アイデンティティと、0.3 Personal Agent以降のユーザー体験。既存のRelease／Activation Gateおよび実装仕様を変更しない。

## 製品コンセプト（CONFIRMED）

**Nagiは「AIを搭載したOS」にとどまらず、ユーザーと継続的に関わり、許可された経験・作業・フィードバックから学び、ユーザーの目的・好み・習慣への理解と実用上の支援能力を育てていくPersonal Agent OSを目指す。**

Nagiの長期的な価値は、利用開始時点のLLMの一般性能だけではなく、利用者との継続的な関係の中で培われた、**その人の仕事と操作に合わせた理解・提案・作業継続の質**にある。ここで「成長」「相棒」は製品体験を説明する比喩であり、AIの意識・感情・自己目的や人間と同等の主体性を主張しない。

この方針は[0.3改訂ロードマップ](roadmaps/Nagi_OS_0.3_Architecture_Roadmap_Revised.md)が既に掲げる、Profile／Memory／Learning／Model Portabilityによる「成長するPersonal Agent OS」を**Nagi OS全体の中核的な製品アイデンティティ**として確認するものであり、0.3へ新たな未承認機能や完了条件を追加するものではない。

## 目指す利用体験と原則（CONFIRMED）

1. **継続利用に応じた個人適応:** Nagiは許可された作業文脈、利用者が採用した提案、繰り返す操作、明示的な指示・訂正などを、DEC-003〜005の範囲で扱う。目的、説明の仕方、作業順序、好みや習慣を徐々に理解し、次回の提案・Contextの選択・作業の再開支援をその人に合わせる。学習を口実に必要のない情報を無差別収集しない。
2. **経験の質を重視:** 単に大量の履歴を保存したり同じ推測を繰り返したりすることを成長とみなさない。利用者による採用・修正・否定と情報の由来を尊重し、誤った理解を訂正できる。習慣は繰り返しと文脈に基づいて判断し、単発操作から勝手に断定しない（DEC-004）。
3. **日常操作とアプリ横断の体験へ反映:** 成長は会話内容の個人化だけに限定しない。Nagiの正規Context／Public Action、Task／Workspace、対応するアプリとの連携を通じ、利用者の作業の探しやすさ、整理、提案、継続性、繰返し作業の改善へ反映する。ただし各機能の具体的な実装・採用条件はそれぞれの決定・承認による。
4. **控えめで実用的な支援:** 利用者の文脈に合った先回りの提案を目指す一方、日常作業を過度に中断せず、DEC-008の積極性設定や通知方針に従う。成長とはAIが権限や主導権を勝手に増やすことではなく、人間にとって適切な支援が増えることを意味する。
5. **モデルと端末を越える連続性:** 利用者の理解を支えるCanonical Memory、Profile、Preferences、Habits、適切なTask／Procedure情報を、特定のLLMの重みやKV cacheから分離してNagi側で管理する。モデル交換や機種更新に際して、保持が許された個人の文脈を原則として継続できる設計を維持する（0.3ロードマップ、DEC-004／013）。端末移行・同期の具体的な方式や対応範囲は既存の別Gateと判断に従う。
6. **利用者が育て方を制御できる:** 何を記憶・利用しているかを確認し、訂正、保護指定、利用停止、明示的な忘却を行える。学習はユーザーの明示指示、元データの分類・所有範囲、正規のPermission／Policy、削除・忘却の規則より優先しない。モデルや端末が変わっても明示的な忘却を破らない。
7. **使わない自由と通常操作の維持:** AIに頼まずGUI／キーボード等で操作できることは変えず、AIが使用できない環境でもOSの通常機能を維持する。自然言語会話、表情・人格演出や特定の対話スタイルを日常操作の前提にしない。

## 境界と明示的な非目標

- **成長はLLMの無制限な自己学習・重み更新や、OSの自律的な自己改造を意味しない。** 既存0.3ロードマップのとおり、モデルのファインチューニングを個人Memoryの主要手段とせず、モデル非依存の状態管理を基本とする。
- **Memory・習慣・成功経験は権限ではない。** 学習内容からActionの許可、データ共有、Cloud送信、Workflowの保存・有効化・改訂、他ユーザー情報のアクセス権限を自動的に導かない。各Actionは現行Permission／Capability／Policyと承認済みTask Scopeの正規経路で再評価する（DEC-001／020／028）。
- **自然忘却と明示的な忘却を維持する。** 「長期的な相棒」とは全情報の永久保存を意味しない。原本の削除／アクセス失効、明示忘却、派生Memory、分類・所有ScopeをDEC-003〜005に従って扱う。アプリ内データとユーザーMemoryを勝手に同一視しない。
- **人格や親密さを強制しない。** 個人化した対話は実用性と利用者の好みを尊重する。擬似感情や自律意思、固定された人間的な人格の再現を要求せず、ユーザーがいつでも通常のソフトウェアとして扱える。
- 本決定は製品コンセプトの確定であって、実装済み、定量的な学習効果を実証済み、正式なReleaseスコープへ新規追加、Workstream開始許可を意味しない。0.1／0.2／0.3／0.4以降の既存Gateとロードマップ境界を維持する。

## 未確定事項（PROVISIONAL）

- 学習前後の支援品質、手戻り、反復作業負担、誤提案などを客観的に評価する方法、ベンチマーク、受入基準、評価対象の長期利用期間。
- 利用者別の言い回し・対話スタイル・個性の適応範囲、ユーザーが調整するUI、訂正の反映速度、誤学習の検出・改善方法。
- 利用可能な履歴・入力種別、Sourceとの連携、ProjectやWorkspaceのContext適用条件、索引・保持方式、モデル・推論時の個人情報保護の具体実装。
- Memory／Learning／Workflow候補を具体的にどの版・Workstreamへ割り当てるか、技術選定と実装時期。既存DEC-004／013／028で確定済みの原則を未決定に戻さない。
