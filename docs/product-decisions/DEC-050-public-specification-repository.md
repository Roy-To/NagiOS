# DEC-050 — 仕様・構想の正本を公開リポジトリへ移す

**状態:** CONFIRMED（保存先とCI分離方針）／PROVISIONAL（Entireの具体設定・移行手順）
**合意日:** 2026-11-15  
**更新日:** 2026-11-16
**関連:** [OPERATING_RULES.md](OPERATING_RULES.md)、[README.md](README.md)、[DEC-046](DEC-046-co-developer-governance.md)〜[DEC-049](DEC-049-development-process-speed-priority.md)

## 決定

1. **仕様・構想の正本は公開リポジトリ `Roy-To/NagiOS` の `docs/product-decisions/` とする。** これまで非公開リポジトリ `Roy-To/NagiOS-internal` に保存していた製品決定(DEC)、ロードマップ、長期ビジョン、設計資料、ベンチマーク、移植ツール、Linux移行の方針文書、開発の進め方の決定を公開する。
2. **今後の仕様決めも公開リポジトリに記録する。** ChatGPT・Codex・その他のエージェントとの会話で仕様や構想を決めたときは、その内容を公開リポジトリの該当DECに記録し、コミットを確認してから「保存済み」と報告する。非公開リポジトリには記録しない。
3. **移管前の記述より本決定が優先する。** 既存文書に残る「Privateに保存する」「Publicへ転載しない」「非公開の開発範囲」などの記述は移管前の履歴であり、本決定が優先する。履歴として本文は残す。
4. **公開しないもの:** 認証情報(パスワード、APIキー、トークン、秘密鍵)、個人情報、個人のユーザー名を含むローカルパス、チャット・会話の識別子。仕様を記録するときもこれらは書かない。

## Entire履歴保存とCIの分離（2026-11-16）

### CONFIRMED

- **公開の `Roy-To/NagiOS` にはコードと決定済み仕様を置き、必要なCIを動かす。** 本体リポジトリのCIを一括停止しない。
- **非公開の `Roy-To/nagi-checkpoints` はEntireの会話履歴・関連メタデータの保存専用とし、CIを動かさない。** Privateを維持し、同リポジトリのGitHub Actionsを無効化する。履歴保存のためのActions workflowは導入しない。
- Private側をNagiOS本体のコード・ビルド成果物のmirrorや、決定済み仕様の第二の正本にしない。履歴とコード変更との関連付けに必要なメタデータは保存対象に含む。
- Entireの履歴を公開側へ転送しない。決定済み仕様は、非公開の会話本文を転載するのではなく、本DECとOPERATING_RULESの公開禁止情報を除いた決定事項として記録する。認証情報はPrivateであっても保存対象に含めない。
- 旧 `Roy-To/NagiOS-internal` への新規記録は再開しない。

### PROVISIONAL／実装時に確認する事項

Entireの利用バージョン、対応するagent／hook、保存先指定の設定名、同期方法、既存履歴の移行要否は、実際の環境と公式仕様を確認して決める。未確認の設定名やコマンドを確定仕様として記録しない。

設定変更の完了、Privateへの履歴到達、公開側への履歴非送信、Private側のActions無効化は、それぞれ実証してから完了と報告する。本記録だけでは実装・移行・保存試験が成功したことを意味しない。

### 実設定と検証記録（2026-11-16）

[Entire運用記録](../development/entire-private-history.md)に、確認した版の公式設定方法、Private／Actions設定、hookによる送信境界、実際のagentでの試験結果と未完了項目を記録する。保存先とCI分離方針はCONFIRMEDのまま、未検証環境・既存履歴移行・無人での自動送信を区別する。

### 適用範囲

Nagi OS開発時のリポジトリ運用に適用する。Nagi製品内のMemory／Activity／Waybackの仕様や、各版のRelease／Activation／Acceptance Gateは変更しない。既存データの削除、公開履歴の書き換え、有料枠の追加をこの決定だけで許可しない。

## 移管の範囲(2026-11-15)

- 移した: 製品決定 DEC-001〜049(旧名称「Jev」時代の置き換え済みファイル5本を除く)、0.3改訂・0.4+・0.5〜1.0ロードマップ、VISION-001、Memory Resource Governor設計、MEMORY-BENCH-01、Porting Toolkit(PT-01・02・06)、Linux移行のADR・整合表・文書整合計画。
- 書き直した: 決定一覧(README)、運用規則、Codex向け手順、ChatGPTプロジェクト指示、ロードマップ索引。
- 公開側の現行文書へ反映した: 非公開側でAGENTS.md、0.1仕様、0.2仕様、実装状況に足していたLinux移行の注記。
- 移さない: 非公開側に残る9月時点のコードのコピー(公開側の方が新しい)、誤ってコミットされたビルド成果物、PR90の検証記録JSON。
- 移管時に削除した情報: DEC-042の会話識別子、PT-01のチャット・ターン識別子、DEC-047のユーザー名入りパス。
