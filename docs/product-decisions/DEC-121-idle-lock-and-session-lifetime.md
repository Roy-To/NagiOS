# DEC-121 — 無操作時の自動ロックとセッションの有効期間

**状態:** CONFIRMED(Q1 自動ロック、Q2 ロック中の扱い、Q3 セッションに絶対的な期限を設けない、Q4 開発イメージの扱い)／PROVISIONAL(ゲストのセッション、端末の種類ごとの初期値、ロック画面に出す通知の内容、実装版)
**最終合意日:** 2026-11-22
**適用候補:** Nagi OS 0.2以降(Linux開発イメージを含む)
**関連:** [DEC-083](DEC-083-nagi-identity-linux-credentials-binding.md)、[DEC-068](DEC-068-nagi-sleep-resume-recovery.md)、[DEC-082](DEC-082-power-lifecycle-coordination.md)、[DEC-096](DEC-096-settings-notifications-context-adaptive-staged.md)、[DEC-113](DEC-113-untrusted-content-and-prompt-injection.md)、[ADR 0063](../decisions/0063-desktop-owner-login.md)、[ADR 0064](../decisions/0064-login-attempt-throttling.md)

## 目的と背景

DEC-083は「ロック中・失効したセッションの権限を無条件に使い続けない」と決めた。一方で、セッションの失効条件とロックの条件は未確定のままだった。Linux開発イメージ(Task24)のログインは期限なし(`expires_at: None`)でセッションを作るため、ログアウトか再起動までセッションが有効のまま残る。

**決定の経緯:** ユーザー(創設者)が、この判断をClaudeに委任した(2026-11-22)。以下の内容は、その委任に基づいて決めたものである。

## 確定した仕様(CONFIRMED)

### Q1 — 無操作が続いたら自動で画面ロックする

1. 初期値は、**無操作が15分続いたらロック**する。
2. 設定で、1分・2分・5分・15分・30分・60分・「しない」から選べる。「しない」を選ぶと、他の人に操作されるおそれがあるという警告を表示する。
3. 次の場合は、すぐにロックする。
   - 利用者が手動でロックしたとき(ショートカットキーや電源ボタン)
   - スリープに入るとき
   - ノートPCの蓋を閉じたとき
4. 無操作の時間は、利用者のキーボード・マウス・タッチの入力で数える。AI・アプリ・背景のジョブの動きは「操作」として数えない。動画の再生中など、アプリの都合でロックを遅らせる仕組みを入れる場合は、別途決める。

### Q2 — ロック中もセッションは保つが、権限は使わせない

1. ロックしてもセッションは終了しない。開いているアプリと作業中の状態は、そのまま残す。
2. ロックを解除するには、ログインと同じ本人確認が必要で、失敗回数による待ち時間(ADR 0064)も同じように適用する。ロックの解除を、新しい権限の付与とは扱わない(DEC-083 3.)。
3. ロック中は、利用者の承認が必要な操作を新しく受け付けない。具体的には次のとおり。
   - 同意ダイアログでの許可
   - Filesの同意
   - AIのActionの承認
   - Ownerの操作
4. ロック中は、ロック画面に通知の本文を出さない。何をどこまで表示するかは、DEC-096の通知の方針に合わせて決める(未確定)。

### Q3 — セッションに絶対的な期限は設けない

1. ログインからの経過時間だけを理由に、セッションを強制終了しない。作業中のデータを失わせないためである。守りは、Q1の自動ロックとQ2の解除時の本人確認で行う。
2. セッションが終わるのは、ログアウト、再起動、電源を切ったあとの起動時の復旧(前回のセッションはすべて終了する。現在の動きを維持する)のときである。
3. 権限の強い操作(Ownerの操作など)で求める再認証は、既存の規則に従い、この決定で緩めない。

### Q4 — Linux開発イメージ(Task24)の扱い

1. 自動ロックを実装するまでは、今の `expires_at: None` のままでよい。自動ロックを実装するときに、Q1〜Q3に合わせる。
2. QEMUの受入試験では、試験を安定させるために自動ロックの時間を長くしたり、無効にしたりしてよい。ただし、製品の初期値(15分)は変えない。

## 例外・禁止・安全境界

- AIやアプリが、ロックの解除・ロック時間の延長・自動ロックの無効化を、利用者の操作なしに行ってはならない。
- ロック中に背景のジョブを続けるかどうかは、既存の決定(DEC-068・DEC-082)に従う。ロック中であることを理由に、新しい権限を与えない。

## 未確定・暫定案(PROVISIONAL)

- ゲストのセッションを、無操作が一定時間続いたときにロックではなく終了(データ消去)するか。その場合の時間。
- 端末の種類(デスクトップ・ノートPC・タブレット)ごとに、初期値を変えるか。
- ロック画面に表示する通知の範囲。
- 実装する版と、受入の条件。
