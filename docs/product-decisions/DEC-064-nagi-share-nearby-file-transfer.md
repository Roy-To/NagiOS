# DEC-064 — Nagi Share（仮称）：近距離の端末間ファイル共有

**状態:** CONFIRMED（純正OS機能としての採用・基本体験・安全境界）／PROVISIONAL（名称・技術・UI詳細・対応範囲・適用版・性能）  
**最終合意日:** 2026-11-16  
**対象:** PC・タブレット・スマートフォンのNagi端末を横断する日常の単発ファイル転送。実装時期・対応端末は未確定  
**関連:** [DEC-002](DEC-002-cloud-ai-data-sharing.md)、[DEC-003](DEC-003-memory-classification.md)、[DEC-014](DEC-014-workspace-state-checkpoints.md)、[DEC-017](DEC-017-third-party-developer-ecosystem.md)、[DEC-023](DEC-023-work-data-centric-os.md)、[DEC-025](DEC-025-cross-app-data-reference-and-updates.md)、[純正ソフトウェア仕様](../NAGI_FIRST_PARTY_SOFTWARE_IMPLEMENTATION_SPEC.md)、[ロードマップ索引](roadmaps/README.md)

## 目的とユーザー体験

AirDropに似た、近くの端末へ必要なファイルをその場で渡せる体験を、Nagiの純正OS機能として採用する。作業名は「Nagi Share」。名称は仮称であり、AirDropとのプロトコル互換を採用・保証するものではない。

Filesや画像ビューア等の共有UIから、近くにある受信可能なNagi端末を発見・選択し、受信側の確認・許可のもと、写真・PDF・一般ファイルを端末間で直接転送できることを目指す。

## 確定した仕様（CONFIRMED）

- **純正OS機能:** 日常の単発ファイル共有をOS共通の体験として扱い、PC・タブレット・スマートフォンのNagi端末を横断する製品目標とする。
- **共有UIからの送信:** Filesや画像ビューア等で対象ファイルを選び、共有UIから近くの受信可能な端末を発見して、送信先を選択する。
- **受信側の確認・許可:** 送信先の選択だけで受信側の許可を代替せず、受信側が確認・許可した範囲で受け渡す。
- **ローカル・オフライン優先:** 必要な写真・PDF・一般ファイルを端末間で直接転送し、インターネットやクラウドアカウントを必須にしない。ローカルの発見・接続手段の選定とは区別する。
- **暗号化と認証:** 転送内容を暗号化し、相手端末の認証と受信許可を適用する。近くにあること、端末名、発見・接続・暗号化の成功だけでアクセス権や共有認可を得たものと扱わない。
- **LLM非必須:** 発見・選択・受信確認・ファイル転送の基本操作にLLMを必須としない。ファイル本文をLLMやクラウドAIへ渡すことを転送の必須経路にしない。

## 例外・禁止・安全境界

- **送信と受信の認可を分離:** 現在のPermission／Capability／Policy、情報区分、外部共有認可、Resourceの所有範囲、User／Profile境界を守る。受信許可は送信元の共有権限を付与せず、同じ所有者の端末であってもProfile境界を迂回しない。ローカル・暗号化転送を理由に既存の共有制約を免除しない。
- **正規のデータ経路:** 対象Resourceの取得・送信・受信・保存は正規の公開契約と現在の権限に従う。DEC-017／023／025の共通Public API、分散正本、非特権AIの境界を維持し、純正であることを理由に未公開データへの包括的アクセスを認めない。
- **安全なファイル取扱い:** 受信ファイルを無条件に信頼せず、既存のファイル検証・Permission／Policyを適用する。受信許可を自動実行・アプリ導入・既存データの無断上書きの許可とみなさない。破損・不完全・失敗・結果不明を転送完了と表示しない。検証・隔離・競合処理の具体方式は未確定とする。
- **Workspace移行・同期とは別:** DEC-014の選択式Workspace移行、チェックポイント・履歴の引継ぎ、同期、暗号化Export／Importの標準方式を置き換えない。単発ファイル転送はWorkspace全体の移行・同期、継続的な更新追従、元データ削除、中断Taskや副作用Actionの再実行を意味しない。
- **ファイルと参照の区別:** ファイルを送っただけで、元Resourceの所有権・Permission・Profile・アプリ内部参照が相手端末へ自動継承されたものと扱わない。DEC-025の共通参照・関連更新とは別の操作として扱う。
