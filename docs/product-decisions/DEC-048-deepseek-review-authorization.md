# DEC-048 — DeepSeekによるNagiコード等レビューへの継続承認

**状態:** CONFIRMED  
**合意日:** 2026-11-14  
**対象:** DeepSeekによるNagiコード・差分・分析資料のレビュー送信  
**関連:** [DEC-002](DEC-002-cloud-ai-data-sharing.md)、[DEC-047](DEC-047-linux-migration-workspaces-and-integration.md)

## 決定事項

2026-11-14の本人の明示決定を記録する。

- Nagiのすべてのコード、差分、分析資料について、非公開のものを含め、DeepSeekによるレビューのために送信することを許可する。
- この許可はすべてのlaneとすべてのpayloadに対する継続承認であり、payloadごとの再確認は不要。
- 認証には、Keychainに保存済みの既存DeepSeek credentialを使用できる。
- credentialそのものは送信しない。

## DEC-002との関係

本DECは、DeepSeekによるNagiコード・差分・分析資料のレビュー送信について、DEC-002に続く具体的な明示承認を記録する。上記の対象と用途では、すべてのlane・payloadに対する継続承認を適用する。
