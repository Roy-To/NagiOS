# NDP-11 — 比較runと実測・改善

状態: 担当確定（Core Developer、2026-11-15）/ NOT STARTED。PT-06。NDP-10と、使用するPT-02〜05の利用可能範囲・実行許可が必要。

## 目的

手動移植とToolkit支援を、同じ機能要求と検証範囲で比較する。速そうという印象や変更行数だけで有用性を断定しない。

## 実施

既存PT-06評価票を使い、対象ソース/SDK/tool版、選ぶ機能、検証条件、環境差、使ったAIの有無を記録する。全項目を埋めるための作業はせず、未測定は未測定とする。

手動のみ、Toolkit非AI、任意のローカルAI補助、任意の外部開発AI利用を区別する。通常の作業にAIを使っていれば「手動のみ」と書かない。契約外の有料APIや未承認ソース転送を比較のために始めない。

環境準備、実装/移植、手戻り、テストの能動時間と待ち時間を区別する。同じ人が続けて試した学習効果や再利用した成果を明示する。条件が違い比較できないときは、無理に速度比や割合を出さない。

## 確認項目案

機能テスト結果、再利用した部分、手修正した部分、未対応API/UI、失敗と再試行、保守上の差を調べる。NDP-09のStage 1/2/3を区別し、target未実行ならそのまま記録する。測定値とcommit/実行結果が対応していることを確認する。

## 完了境界

少なくとも選択した評価ケースについて、実施した方式と未実施方式、結果、比較限界、具体的改善点が説明できる。toolが未実装なら評価計画までであり、比較run完了ではない。自作fixtureと実アプリの実績を別に扱う。

## 改善へ戻す

診断rules、generator、UI mapping、検証adapter、SDK不足のどこが原因かを分け、担当へ小さな再現例を返す。他ownerのコードを直接修正する許可にはしない。NDP-12で次の作業を整理する。
