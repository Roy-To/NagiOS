# Claude / Codex共通のレビュー指示

TASK、BASE、HEADは実在する値を指定します。レビュー対象HEADを固定し、編集者と同じ作業フォルダを変更しません。

```text
TASK: レビュー対象のNDP-ID
BASE: 実在する比較元commit
HEAD: 実在するレビュー対象commit

この差分を独立レビューしてください。既存AGENTS.md、確定DEC、スターターキットの共通規則と対象task、開始承認を読み、実コード・テストを照合してください。原則read-onlyです。自動修正、branch切替、commit、mergeはしないでください。テスト実行はレビュー用に許可された環境と出力先だけで行ってください。

重点:
- PT-01やSDK/validatorの二重実装、架空API、契約の無断変更。
- 指定外への走査・書込み、symlink逸脱、入力破壊、秘密の出力。
- コメント/文字列の誤検出、未知API、壊れた/巨大な入力。
- UIの構造解析と本物の描画/入力接続の混同。
- Stage 1からのbuild script実行、shell injection、未承認subprocess。
- 偽テスト、Mockしか試していないproduction経路、host/targetの成功混同。

問題があれば重要度、file:line、実際に起きる条件、影響、最小修正案を示してください。確証がないものは疑問と区別してください。実行していないテストは未実行と書き、問題が見つからなくても無欠陥保証にはしないでください。修正は元の実装担当へ返してください。
```
