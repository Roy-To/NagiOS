# Shell / Notes Supervisor Candidate

This package preserves the lane's Shell surface, Settings save-feedback, and
Notes child lifecycle candidate in repository-relative form.

It is not production-ready. Its Supervisor adapter remains unavailable unless
the boot owner supplies the authorized Task41 route and Task24 exact process
proof. The candidate Notes bootstrap is not the production NIPC protocol, and
the direct NoteStore bridge is not a C2 typed client. The storage adapters must
receive an existing broker-owned handle; they do not grant authority, open a
device, or mount a provider.

Passing fixture or type checks for this package does not establish a production
Shell-to-Supervisor-to-Notes path or Linux-image acceptance.
