# Code of Conduct

Nagi OS welcomes respectful participation from people with different backgrounds
and levels of experience. This project-specific policy is inspired by the
[Contributor Covenant, version 2.1][covenant].

## Scope

This policy applies to project spaces, including repository issues, pull
requests, reviews, discussions, and project-related events or communications.

## Expected behavior

- Be respectful, patient, and constructive.
- Discuss ideas and evidence without attacking people.
- Accept good-faith correction and feedback.
- Respect privacy, licensing, security boundaries, and the stated scope of a
  contribution.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, sexualized attention,
doxxing, publishing private information, and sustained disruptive conduct are
not acceptable. Do not retaliate against someone for making a good-faith report.

## Maintainer response

Project maintainers are responsible for interpreting and applying this policy.
Depending on the situation and their authority, they may ask for a correction,
remove or edit content, close a discussion, or restrict participation in
project spaces. This policy does not promise a response time or a particular
outcome.

## Reporting an incident

Do not report a conduct incident in a public issue, pull request, or comment.
Do not include credentials, personal information, private correspondence, or
identifying details in a public report.

For an incident in an issue, pull request, or comment, open GitHub's
**Report content** menu. If GitHub offers **Report to repository admins**, that
sends a report to the repository maintainers. The availability of this option
depends on the repository's GitHub moderation settings.

If that option is not available, or you need to report a user or content to
GitHub, follow GitHub's [reporting guidance][github-reporting], which explains
how to contact GitHub Support. A report to GitHub Support is handled by GitHub
and does not automatically notify the Nagi maintainers.

This repository does not publish a dedicated private conduct-report email
address. Do not guess or reuse a contact address. For security vulnerabilities,
follow [SECURITY.md][security] and its private-reporting instructions. If there
is an immediate threat to someone's safety, contact local emergency services.
